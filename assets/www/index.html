JSON

JSON strings are pretty-printed for editing and stored minified. Blob values (arrays, structs, floats) are read-only: their layout is not stored in NVS, so there is nothing safe to edit them against — “View” shows them as a hex dump.

Editor

Text files up to 4 KB can be edited here. Everything else is read-only: images are shown as images, other binaries as a hex dump. Previews cover the whole file, not just its beginning. Uploading whole files is not supported yet — use “pio run -t uploadfs”. Removing /www leaves the portal on its built-in page, so it stays reachable.

Preview

Display

The device draws a frame in horizontal strips and never keeps a whole frame in RAM, so the browser collects them here - one strip per request. "Live" already matches the rate the device itself redraws at; a moving picture may show a seam between strips, because neighbouring strips come from different device frames.
